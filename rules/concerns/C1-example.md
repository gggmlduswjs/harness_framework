# C1. 설정 단일 출처 (예시)

## When to Apply

- 환경 변수나 설정 파일을 읽는 코드를 쓰거나 고칠 때
- 새 설정 키를 추가할 때

## MUST

- 설정값은 `{설정 모듈 경로}` 에서만 읽고, 다른 코드는 그 모듈이 내보내는 값을 쓴다.
- 새 설정 키는 설정 모듈에 기본값·설명과 함께 선언한다.

## MUST NOT

- 설정 모듈 밖에서 `os.environ` · `process.env` · `getenv(` 로 직접 읽지 않는다.
- 같은 설정 키의 기본값을 두 곳 이상에 적지 않는다.

## PREFER

- 설정 모듈은 시작 시 한 번 읽고 검증해, 빠진 키를 그 자리에서 실패시킨다.

## Exception

- 설정 모듈 자체, 그리고 테스트 픽스처의 환경 변수 주입.

---

> 📌 **조항 쓰는 법** — 강제할 수 없는(기계·LLM 이 코드에서 판정 못 하는) 조항은 두지 않는다.
> 타입상 아무 효력 없는 선언을 "반드시 선언한다" 로 적어 두면, 어긴 것을 어겼다고 말할 근거가 사라진다.
> 판정 기준이 없는 조항은 PREFER 로 내리거나 지운다. (원본: ibare/FACET rules/concerns/C1 의 교훈)
